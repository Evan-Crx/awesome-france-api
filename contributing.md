# Contributing to Awesome France API

Merci de contribuer à cette liste. Les règles pour soumettre une API :

## Critères d'acceptation

1. **Utile aux développeurs en France** : API officielle, gouvernementale, ou produit SaaS FR largement adopté.
2. **Plan gratuit disponible** : au moins 500 requêtes par mois honnêtement accessibles (pas juste un trial limité).
3. **Documentation publique** accessible sans contrat commercial préalable.
4. **URL fonctionnelle** vérifiable.

## Format d'une entrée

```markdown
- [Nom de l'API](https://url-officielle) — Description courte (~200 caractères max) qui dit ce qui rend l'API utile : volume de données, cas d'usage, stack technique, conditions d'accès.
```

## Règles de placement

- **Catégorie adaptée** parmi celles du README.
- **Ordre alphabétique** dans la section.
- Pas de double-référencement d'une même API dans plusieurs catégories (choisir la plus pertinente).

## Process de PR

1. Fork le repo.
2. Branche `add-nom-de-lapi` ou `update-nom-de-lapi`.
3. Modifie uniquement `README.md`.
4. Titre de PR : `Add <Nom>` ou `Update <Nom>`.
5. Une API par PR.

## Suggestions de nouvelles catégories

Ouvre une issue avant de PR si tu penses qu'il faut une nouvelle section principale. Exemples envisageables : Banque & paiement, Agriculture, Emploi & formation, Sport.

## Nettoyage

Les entrées mortes (URL qui renvoient 404 pendant plus d'une semaine) seront retirées par PR des mainteneurs sans préavis.
